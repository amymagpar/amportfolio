Building Anticipation: Designing for the 6-10 Month Wait

The Challenge

Lucid's production timeline meant customers waited 6-10 months between reservation and delivery, a critical churn risk period. How do we keep customers engaged and build excitement when the product doesn't exist yet?

Design Strategy: Progressive Engagement

Rather than leaving customers in limbo, I designed a habit-forming dashboard that gave them reasons to return weekly: tracking their vehicle's progress, completing required tasks (financing, insurance), and learning about their future car.

Data Integration Architecture

The experience required integrating real-time data from multiple sources:

  • Salesforce CRM: Reservation status, delivery timeline estimates
  • Bank of America API: Financing approval status and loan details
  • Delivery logistics: Vehicle production milestones and shipping updates
  • Vehicle telemetry: Once the vehicle was delivered, the dashboard changed to show vehicle details.

Technical Constraints & Creative Solutions

  • Phased API availability: Designed graceful empty states and "coming soon" indicators for features launching post-launch.
  • API rate limits: Implemented smart caching—frequently accessed data refreshed hourly, critical updates real-time.
  • Multi-jurisdictional delivery rules: Designed adaptive interface handling state-specific requirements. Some states mandated dealership in state causing a need for home delivery.
  • Content creation timeline: Repurposed owner's manual content into bite-sized learning modules rather than creating new content from scratch
  • Financial data security: Collaborated with legal to design PII masking (last 4 digits) while maintaining usefulness
  • Mobile-first with offline access: Designed progressive web app with cached data views for customers without connectivity
