Personalized Education Pathways

My research showed overwhelm for first-time EV buyers vs. experienced EV owners.

Data-Driven Pre-Delivery Engagement

Reservation holders had a 6-month wait with zero engagement → churn risk.

Design decision:
Progressive task completion (insurance, financing, delivery scheduling) to build anticipation and habit formation in the dashboard.

Cross-functional coordination:
Partnered with finance and delivery ops to surface real-time data (financing approval status, delivery timeline) via Salesforce APIs.

Impact:
46% conversion from reservation to purchase.

Data Integration & Dashboard Architecture: Building Habits

Problem: Customer data was siloed across systems (Salesforce CRM, Bank of America API, delivery logistics, vehicle telemetry)

A phased release approach:

Integrated real-time Salesforce data to display financing approval status, delivery timeline, and service appointments.

Created observability patterns for customer support team to monitor data sync issues.

Built progressive disclosure interface to handle varying data availability (e.g., delivery date uncertain until vehicle in production).

Constraints navigated:

  • Some APIs were not ready for launch
  • API rate limits required caching strategy for frequently accessed data
  • No time to create new content - scrapped manual for educational content.
  • PII/security requirements for financial data display
  • Mobile-first design with offline-capable data views
